# Roblox Music Hub

Cr4Zy Hub is a Roblox music player interface built with a LocalScript. This Roblox music hub lets players add audio asset IDs and track names to a queue, filter and manage tracks, control playback, and adjust volume for audio assets their experience is allowed to use.

## Install

1. In Roblox Studio, open your experience.
2. Add a LocalScript to `StarterPlayer > StarterPlayerScripts`.
3. Copy the contents of `src/MusicHub.client.lua` into the LocalScript.
4. Publish or run the experience to load the music hub for the local player.

## Use

1. Enter a numeric audio asset ID and an optional track name in the add bar.
2. Select Add track. If no name is entered, the player assigns a default track name.
3. Select a queue item to play it. Use the previous, play/pause, and next controls to manage playback.
4. Type in the queue filter to find tracks, or select the remove control on a track to remove it.
5. Click or tap the volume bar to set playback volume. Use the close button to hide the hub.
